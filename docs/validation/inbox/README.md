# V00 Validation Evidence Inbox

Use this directory only for new, privacy-safe V00 evidence that a later run can
inspect. It is an intake location, not proof that an item is valid or a gate is
passed.

- Do not add names, email addresses, phone numbers, learner lists, raw
  correspondence, credentials, or access-controlled source content.
- For practitioner and recruitment confirmations, store the controlled original
  outside Git and add only a pseudonymous evidence identifier, date, status,
  qualification or reach summary, and controlled-reference location.
- Preserve source date, inspection date, market, role, seniority, stability,
  and exclusion reason for public-demand evidence.
- A new item triggers validation against the V00 protocol; it never changes the
  V00 decision automatically.
